# Project Journal — Chronological Scratchpad

This is a durable, versioned scratchpad for brainstorming, experiments, multi-agent notes and context compaction. **A journal proposal is not design canon.**

## Create new journals
Use:
- **YYYY-MM-DD-brainstorm-topic.md** for exploratory discussions
- **YYYY-MM-DD-work-topic.md** for implementation/research logs
- **YYYY-MM-DD-handoff-topic.md** for agent coordination
- Add "-02" for another same-topic note on the same day

Keep summaries factual and update this index when creating new entries. Do not use journal entries to silently supersede accepted ADRs.
