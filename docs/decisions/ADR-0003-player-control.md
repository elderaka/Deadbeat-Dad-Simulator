# ADR-0003 — Bapak as Sole Directly Controlled Character

## Context
The design compared managing an entire family like The Sims with controlling only Bapak while family members pursue autonomous goals. An earlier reply suggested the latter strongly, but no explicit user lock exists.

## Proposal
Directly control Bapak; wife, children and neighbors behave via simple autonomous routines. Player influence occurs through schedules, finances, conversation, shared activities and help.

## Benefits
Higher identification with the absurd protagonist; clear resource and responsibility boundaries; interesting family autonomy.

## Risks
Poor NPC decisions feel unfair; players may want more control; expensive AI implementation if oversimulated.

## Alternative
Household-level commands for all members or a limited delegation/planning interface.

**Proposed — needs creator approval.** Resolve [Q-001](../gdd/12-open-questions.md) before committing core controls/architecture.
