# Agent Task Template

Copy this into a task description or journal file:

## Objective
What exact feature, design decision, or validation is needed?

## Scope
Paths to read; paths allowed to edit; out-of-scope systems.

## Source of truth
Links to accepted ADRs and canonical GDD. Cite any proposals explicitly as hypotheses.

## Constraints
Platform assumptions, performance, offline requirement, no gambling, no multiplayer MVP, tone boundaries.

## Plan
Concrete small steps; expected artifacts and acceptance criteria.

## Evidence / verification
Which tests, playtest notes, screenshots, or review findings will establish success?

## Handoff result
Changed files and commits; tests performed; unresolved issues; requested creator decisions; next step.

**No plan should be presented as an implementation completed.**
